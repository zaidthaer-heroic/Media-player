# مشغّل زيد 🎬🎵

تطبيق أندرويد (Kotlin + Jetpack Compose + Media3) لتشغيل فيديوهات وموسيقى الجهاز، بدون إعلانات وبدون إنترنت.

## المزايا الحالية
- قسم **الموسيقى**: قائمة كل الأغاني، تشغيل بالخلفية، إشعار تحكم، مشغّل مصغّر (سابق/تشغيل/تالي)
- قسم **الفيديو**: قائمة بصور مصغّرة، تشغيل بملء الشاشة، يتذكّر آخر موضع مشاهدة، التحكم بالسرعة من أيقونة الإعدادات
- واجهة عربية RTL، وإيقاف الموسيقى تلقائياً عند تشغيل فيديو

## البناء عبر GitHub
1. أنشئ مستودعاً جديداً وارفع كل محتويات هذا المجلد (مع مجلد `.github`).
2. افتح تبويب **Actions** ← **Build APK** ← انتظر انتهاء البناء (3-6 دقائق).
3. حمّل الملف **MediaPlayer-APK** من أسفل صفحة التشغيل، فكّ ضغطه وثبّت `app-debug.apk` على هاتفك (فعّل "التثبيت من مصادر غير معروفة").

## البناء محلياً
افتح المجلد في Android Studio ثم Build ← Build APK(s).
