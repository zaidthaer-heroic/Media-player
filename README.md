# مشغّل زيد 🎬🎵

تطبيق أندرويد (Kotlin + Jetpack Compose + Media3) لتشغيل فيديوهات وموسيقى الجهاز، بدون إعلانات وبدون إنترنت.

## المزايا الحالية
- قسم **الموسيقى**: قائمة كل الأغاني، تشغيل بالخلفية، إشعار تحكم، مشغّل مصغّر (سابق/تشغيل/تالي)
- قسم **الفيديو**: قائمة بصور مصغّرة، تشغيل بملء الشاشة، يتذكّر آخر موضع مشاهدة، التحكم بالسرعة من أيقونة الإعدادات
- واجهة عربية RTL، وإيقاف الموسيقى تلقائياً عند تشغيل فيديو
